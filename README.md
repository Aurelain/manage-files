# manage-files

## Usage
1. Visit [manage-files](https://aurelain.github.io/manage-files/) (or open `index.html` locally)
2. Add one or more root directories
3. You may use the filter with regular expressions which can be logically combined using `&`, `|` or `()`.


## Notes
- The files will be displayed in a flat column (regardless of depth).
- If the file is a picture, it will be previewed. 
- If two or more directories contain the same file name (!), the files will be displayed next to each other, 
horizontally.
